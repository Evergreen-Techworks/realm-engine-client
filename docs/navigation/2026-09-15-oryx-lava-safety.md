# Oryx waypoint and damaging-ground safety follow-up

2026-09-15 Owner reported Oryx 1/2/3 waypoints drawing without travel, and a death after automatic movement entered lava while taking projectile damage. Owner closed private 1.0.7. Private 1.0.8 remains staged, not activated, while this follow-up is validated.

2026-09-15 Reproduced a concrete shared native waypoint failure: when global capture cannot prove scene readiness, Runtime reports a partial result with no corridor; UDodge converted that into a HOLD even though local routing could validate a short waypoint. The production-loop pending-capture fixture travelled zero tiles in 60 seconds under both collision rules before the fix. Added explicit `capturePending` metadata so only unavailable global capture falls back to the existing locally validated route. Unknown terrain, blockers, collision and projectile checks remain authoritative. Actual Runtime tests verify pending-capture metadata and stale epoch/corridor rejection; production-loop tests verify both walking and refusal to cross a blocking wall. This reproduces a matching failure path, not direct observation of the owner's Oryx session.

2026-09-15 Found an intentional unsafe-walk exception: the navigation search accepted damaging ground when a clean detour exceeded a cost allowance, and both game-thread and worker solvers disabled safe-walk while following that route. Removed that override at all three consumers and changed safe-walk navigation to a hard damaging-ground exclusion. An explicit user safe-walk opt-out still permits the old costed crossing. Already-on-hazard escape rules remain unchanged. This cannot protect against incorrectly classified or unseen hazards, and is not a no-death guarantee.

2026-09-15 Test-first lava reproduction crossed the damaging row for ten frames under each collision rule. Added no-crossing, long clean detour and simultaneous-shot-pressure scenarios with zero damaging-ground frames and zero hits required. Corrected the supposedly enclosed fixture's end gaps and retained its old open-ended geometry separately as the detour scenario. Added planner tests for strict exclusion, explicit opt-out and clean detours beyond the old allowance. Ordinary scenario safety assertions were not waived; the lava-only goal now explicitly expects refusal rather than successful unsafe arrival, reflecting the owner's requested safety policy.

2026-09-15 Client suite remains 66 files / 656 tests. Final native/Windows validation and delivery results will be appended after completion. All previous MBC/Lost Halls, Lich/Ghost King skip and legacy-collision smoothing changes remain included. Dense-boss whole-arena combat planning is still unfinished.
