# Navigation status bridge

2026-09-15 Ruling: preserve the existing synchronous boolean `Dodge.navigateToPosition` API. `client/packages/sdk/src/dodge/Dodge.ts` and its bridge return a boolean, not a promise. Add `Dodge.onNavigationStatus` subscription instead of introducing unhandled asynchronous rejections. Controller approved this interpretation of the binding unchanged-API intent.

2026-09-15 Contract: `scriptNavigationGoal` carries one atomic `requestId,x,y` string. IDs are process-global, timestamp-seeded safe integers and remain unchanged when a script reaffirms the same waypoint. Native handlers must parse the complete integer without 32-bit truncation. They update legacy movement too; this is not a second pathfinding owner. Atomic goal commands are never replayed after DLL reconnection.

2026-09-15 Native status: `{type:'navStatus', goalKind:'point'|'ring', goalId, generation, state:'routing'|'arrived'|'partial'|'unreachable', reason}`. Point goalId is the request ID; ring goalId is the enemy ID. Generation is the native map epoch. The bridge accepts only its current point request, ignores lower accepted epochs, invalidates on HELLO/MAPINFO/clear, and sends arrival/unreachable to subscribers with the original destination. Map reset rejection has no farmer cooldown. The native emitter queues at most 64 validated messages and never writes the pipe on the game thread. Reason is an empty string or lowercase letters/underscores, maximum 128 bytes.

2026-09-15 Farmer: all ten point navigation call sites use the common travel helper. Failed destinations have a bounded 30-second retry exclusion, cleared on map change. Existing selectors skip them; matching captured goal owners are released without discarding an unrelated encounter. Subscriptions are replaced on map reset and removed on stop. Subscriber exceptions cannot interrupt another subscriber or the pipe dispatcher.
